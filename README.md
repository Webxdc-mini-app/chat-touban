# ちゃっと当番表 1.2.0

避難所や地域行事の当番を、みんなで決めて引き継ぐためのアプリです。箱舟プロジェクトのTinyBoxとDelta Chatで使うことを想定しています。インターネットが使えないときも端末で入力でき、通信経路が戻るとDelta Chatを通して更新を共有します。

当番ごとに、必要人数、作業時間、場所、リーダー、参加予定、実際の参加、引継ぎを記録できます。スマートフォンを持たない人の代理登録・代理記録もできます。

## 最初に読む資料

画面図と早見表を入れた、全11章の日本語操作マニュアルです。日本語表示のバージョン1.2.0を基準に説明しています。図は一部の項目を省略して操作位置を分かりやすく再構成した説明図で、実際の端末では配置が異なることがあります。

- [HTML版操作マニュアル](chat-touban.html) — ブラウザーで読む。目次から移動でき、画像も内包しているため単体・オフラインで開けます。

## どのファイルを使うか

| ファイル | 使い方 |
|---|---|
| [chat-touban-1.2.0.xdc](chat-touban-1.2.0.xdc) | Delta Chatのグループに添付して、みんなで使うアプリ |
| [ブラウザーデモ](chat-touban-demo.html) | ブラウザーで一人で試すデモ。CSS・JavaScript・アイコンを内包し、他のファイルは不要 |

## みんなで使い始める

1. **会場の準備担当者**が、TinyBoxなどを通じてDelta Chatのグループ内でメッセージを送受信できる状態にします。アカウントやサーバーの設定が分からない場合は、担当者に確認してください。
2. グループに **chat-touban-1.2.0.xdc** をファイルとして添付します。
3. 全員が **同じグループの同じアプリメッセージ** を開きます。各自でアプリを送り直すと、別の当番表になります。
4. 「更新・使い方」で会場名を保存し、「参加者」で人を登録します。
5. 「役割ボード」で日付と朝・昼・夜を選び、「＋ 当番」を押して当番を作ります。必要なら役割ひな形を使い、人数・時間を調整します。
6. 本人と相談して、当番カードの「参加者・実績を管理」で参加予定を記録します。仕事のあとに参加済み・不参加を記録します。
7. 引継ぎを追記し、次の担当者が「読んだことを記録」を押します。重要な交代は直接確認してください。

通常のグループチャットで使ってください。配信チャットは共同編集に対応していません。新しく添付したアプリは別の当番表で、旧記録は自動移行されません。

## 一人で試す

1. **index.html** をブラウザーで開きます。
2. 「単体HTMLのデモモード」と表示されていることを確認します。
3. 「デモデータを追加」を押し、当番や引継ぎを操作します。

デモの記録は、このブラウザー内だけに保存します。Delta Chatには共有しません。デモで入力した内容を本番アプリに取り込む機能はありません。本番の .xdc にデモ人物を自動で追加することもありません。

## 参加状態の違い

| 状態 | 意味 | 必要人数の充足に数える |
|---|---|---|
| 参加希望 | 参加したいと申し出た段階 | いいえ |
| 参加予定 | 本人と相談して参加する予定が決まった | はい |
| 参加済み | 実際に作業に参加した | はい |
| 不参加 | 実際には参加しなかった | いいえ |
| 取消 | 誤登録や取りやめた予定を取り消す。履歴は残る | いいえ |

必要人数が0、終了した当番、活動休止中の参加者、夜間不可に該当する作業では、新しい参加希望・予定を登録できません。過去に参加した事実は記録できます。

リーダーは交代できる調整役です。全員が編集・代理記録できます。権限の強制や本人認証はありません。リーダーを選んでも、その人の参加予定は自動では登録されません。

## 通信がないときと同時編集

- 「端末保存済み」は、この端末に保存できた表示です。
- 「Delta Chat受付待ち」は、アプリからDelta Chatへ渡す処理を待っている件数です。
- 「受付待ちなし」でも、**全員への到達が完了したとは限りません**。
- 共有にはTinyBoxのWi-Fi・ローカルメールなど、Delta Chatの通信経路が必要です。端末が近くにあるだけでは共有されません。
- 同じ項目を別々に変更したときは、両方を候補として残します。「更新・使い方」の「競合の確認」で相談し、採用する内容を選びます。

急ぎの交代や安全に関わる連絡は、対面・紙の掲示も使って確認してください。

## 15言語の表示

日本語・英語・中国語（簡体字）・韓国語・ベトナム語・タガログ語・フィリピン語・ポルトガル語・ネパール語・スペイン語・フランス語・ドイツ語・アラビア語・インドネシア語・ロシア語に対応しています。

画面上部で選択し、この端末だけに保存します。オフラインで切替可能です。アラビア語では右から左に表示します。**入力された呼び名・当番名・引継ぎ文は自動翻訳しません。** ひな形やデモを新規作成したときの内容は、作成時の言語で記録されます。

## 個人情報と記録の保管

呼び名・班名・番号を使い、住所・病歴などは書かないでください。記録はチャット全員に共有され、あとから回収できません。

JSONは全履歴の参照・保管用、CSVは全日付の当番・実績を表計算で見るための出力です。JSONの取込・復元は未対応です。CSVの見出しと保存値は日本語のままです。保存先・送信先を確認し、Delta Chatのバックアップも必要に応じて利用してください。

当番の終了や予定の取消を行っても、履歴は残ります。一括削除・リセット、他アプリとの自動連携はありません。

## 検証と導入前の確認

アプリは、同時編集、保存・復元、参加実績、多言語表示など32項目の自動試験を行っています。Delta ChatとTinyBoxの実機配送試験、実画面確認、各言語話者による翻訳校正は未実施です。導入前に現地の端末2台以上で、更新共有・切断と再接続・再起動・同時編集の候補確認を試してください。

マニュアルの図は説明用の画面図です。実機の動作を証明するスクリーンショットではありません。
